# Off-Page Backlink Plan — Zyphuel (2026-10-23)

A verified checklist of **famous, legitimate platforms** where Zyphuel can create a real
company profile and earn genuine backlinks — plus ready-to-use templates.

> **Ground rules (permanent):**
> 1. **No fake or bought links.** Google's spam policies penalise link schemes; a bought
>    "dofollow" link is a ranking risk, not an asset.
> 2. **NAP consistency everywhere.** Every profile must carry the exact same Name, Address
>    (service area), Phone and Website (see "Canonical profile block" below).
> 3. **Nofollow is fine.** Most social/directory links are nofollow — their real value is
>    trust, discovery, referral traffic and brand search signals, not raw link equity.
> 4. **Truthfulness (AGENTS.md):** only genuine claims, no exaggeration, no fake store
>    badges or fake launches on any profile.

| **BusinessList.pk** | Only a paid highlighted listing shown; no verified free tier |
| **Clutch** | B2B agency/service-provider category; listing a fuel-delivery startup as an agency would misrepresent the business |
| **GoodFirms** | Software/service-vendor directory, review-gated — poor category fit |
| **Cylex** | No verified Pakistan submission route in its live flow |
